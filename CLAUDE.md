# Field Notes

## Overview

Personal working notes: a profile summary of past projects and a running backlog of technical writing ideas, kept so drafts are grounded in real work rather than written from scratch each time.

## Tech Stack

No application code — documentation only.

## How to Run

Nothing to run. Reference `notes/profile.md` and `notes/backlog.md` when drafting.

## Project Structure

```
field-notes/
  notes/
    profile.md    # Summary of past projects, derived from public repos
    backlog.md    # Running list of writing ideas with source references
  drafts/
    *.md          # Drafted writeups, one per idea, marked with a status
```

## Key Decisions

- Nothing here is published automatically. Drafts are a personal step before writing something up elsewhere.
- Ideas are grounded in actual repos/commits — no invented claims.
